# Comprehensive Airbnb Market Data Analysis

An exploratory data analysis (EDA) and data processing pipeline analyzing real-world lodging trends, pricing factors, and seasonality.

## Overview
- Cleaned and prepared large real-world datasets, handling missing values and data inconsistencies.
- Performed extensive exploratory data analysis (EDA) to evaluate price drivers across locations and property types.
- Generated multi-variable visualizations and analyzed time-series trends to uncover seasonal demand shifts.

## Tech Stack
- **Language:** Python
- **Data Analysis & Manipulation:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
